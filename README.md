# Paddy Disease Classification

Image classification project based on the Kaggle Paddy Doctor competition.

## Objective

The objective of this project is to classify paddy leaf images into one of ten disease/health categories using PyTorch and TorchVision.

## Dataset

The dataset contains images belonging to the following classes:

- bacterial_leaf_blight
- bacterial_leaf_streak
- bacterial_panicle_blight
- blast
- brown_spot
- dead_heart
- downy_mildew
- hispa
- normal
- tungro

The original dataset is not included in this repository.
